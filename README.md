
# UVADER ENGINE

A modular 2D and 3D game development engine.

## Overview

Uvader Engine is an experimental cross-platform
game engine with a browser-based editor and a
native C++ runtime.

## Features

- 2D rendering
- 3D rendering
- Scene management
- Asset management
- Modular architecture
- Native C++ foundation
- Browser-based editor

## Technology

- TypeScript
- Three.js
- Canvas API
- C++
- CMake
- Vite

## Development

Install dependencies:

    npm install

Start the editor:

    npm run dev

Build:

    npm run build

## Project Status

Version: 0.1.0

Development stage: Early foundation.
